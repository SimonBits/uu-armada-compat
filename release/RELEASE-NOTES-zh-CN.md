# UU Armada 兼容工具 v0.1.0

为 Armada ARM64 提供严格匹配的 xt_nat 兼容模块，修复已验证环境中官方 UU Linux 加速器的 DNS DNAT 初始化兼容问题。安装后随开机准备模块，日常由用户通过官方 UU 手机 App 控制加速。

**独立社区工具，非 UU 或 Armada 官方产品；不包含、不修改、不分发 UU 官方程序。**

## 支持范围

- Armada `20260926.c2fd048`
- Armada `20261010.c3d178c`

一套安装器按实际内核 Build ID、配置、依赖、ABI 和模块指纹严格选择。其他构建及 OTA 后内核不保证兼容，不匹配时安全停止或跳过开机加载。

## 本版内容

- 四个入口：install.sh、upgrade.sh、uninstall.sh、status.sh。
- 开机加载、幂等安装、离线升级及安全卸载事务。
- 加速期间拒绝卸载，同时保留开机加载和完整安装状态。
- `sudo ./status.sh --must-gather` 生成白名单英文诊断包，默认保存至原用户家目录。
- 两份模块原样复用，未重新构建；保留源码、配置、许可证及构建来源。

下载压缩包及 SHA-256 文件，验证后在独立目录解压，按照 README 安装。用户自行安装/配对官方 UU，工具不会自动触发加速。

已有已验证双内核候选的用户，请停止手机加速后从正式包执行 `sudo ./upgrade.sh`。完整已知旧包按指纹迁移；未知修改和未完成卸载不会被强行覆盖。

## 已知情况与验证边界

- TF 卡环境下特定重启场景存在设备发现延迟反馈，原因未确认，不能归因于 xt_nat。
- 用户确认候选主要真机验证完成；本次正式包整理只做离线回归。0926 重复启停次数、长时间稳定性及正式包迁移仍需逐项补充验收记录。
- 外部模块仍有内核运行风险，保留本机恢复手段；不强制加载/卸载，不修改 bootc、启动分区或 UU 二进制。
