# UU Armada 兼容工具 v0.1.0

为指定 Armada ARM64 内核补充 `xt_nat`，解决官方 UU Linux 加速器初始化时遇到的 DNS DNAT 兼容问题。安装一次后，兼容模块随系统启动加载，日常通过官方 UU 手机 App 控制加速。

**本工具非 UU 或 Armada 官方产品，不包含、不修改、不分发 UU 官方程序。** 请自行按官方流程安装 UU 并完成手机配对。

## 支持范围

仅适配以下 Armada 内核构建：

- `20260926.c2fd048`
- `20261010.c3d178c`

安装器按实际内核 Build ID、配置、依赖及模块身份严格核验，不只看版本名称。其他 Armada 版本或内核更新后的兼容性不作保证；不匹配时停止安装或跳过开机加载，不强制加载。

## 安装

先保存重要数据，确认本机终端或手动恢复方式可用。接入外部电源，或确保电池电量至少 20%。若已安装 UU，先在手机上停止加速。

从可信来源取得压缩包和校验文件，在新的独立目录中操作：

```sh
sha256sum -c uu-armada-compat-0.1.0.tar.gz.sha256
tar -xzf uu-armada-compat-0.1.0.tar.gz
cd uu-armada-compat-0.1.0
sha256sum -c SHA256SUMS
sudo ./install.sh
```

阅读中文风险确认，输入 `yes` 继续。安装器会验证模块、准备系统自带依赖、检查隔离 DNAT 功能，再配置开机加载；不会替你安装 UU、启动加速或重启设备。

安装成功后，自行安装官方 UU、完成配对，再手动重启并检查状态。已有 UU 无需重装。此后在手机 App 上开始加速，并用实际网络使用效果确认。

重复运行同一安装包时，会核验已有状态，正常则提示无需重复操作。不要覆盖旧安装目录或删除状态文件来绕过检查。

## 状态与故障检查

```sh
sudo ./status.sh
sudo ./status.sh --must-gather
```

第一条显示内核、模块、开机加载和 UU 状态。第二条生成英文诊断压缩包，默认保存在原调用用户的家目录，权限为 0600，不污染安装包目录。

诊断仅收集白名单信息，不收集账号、Token、二维码、配对配置或网络载荷，也不会自动修复系统。遇到内部故障时，请保留提示和诊断包，提交给维护者。

## 升级

从新的可信离线安装包目录执行：

```sh
sudo ./upgrade.sh
```

建议先停止手机加速。同一正式包无需重复升级；已认可的旧包或双内核候选可安全迁移，未知同版本内容会被拒绝。工具不自动下载、编译或后台更新。

## 卸载

先在手机上正常停止 UU 加速，再运行：

```sh
sudo ./uninstall.sh
```

模块或 TUN 正在使用时会拒绝卸载，**不会因此禁用开机加载或删除安装文件**。安全检查通过后才正常卸载；不强制卸载、不清空防火墙、不删除 UU 或账号信息。

若提示上次卸载未完成，请保留现场，按提示继续同一卸载流程。不要手动删除 systemd 文件、模块或状态目录。详细恢复边界见 [技术说明](TECHNICAL.md)。

## 已知情况

- TF 卡环境下，特定重启场景中可能出现手机发现设备延迟。**原因尚未确认，不归因于 xt_nat。** 本轮没有统一复现条件或等待时长结论；出现时先检查状态，不要据此反复重装或修改网络。
- 首次安装后服务可能显示未运行，但模块已由安装器加载；下次正常开机后服务通常为 active/exited。模块状态以 `status.sh` 为准。
- 系统 OTA 后若内核不匹配，需等待对应适配；不要强制加载旧模块。其他内核不在本包支持范围内。
- 外部内核模块存在运行风险，并会留下外部模块 taint 标记，卸载后该标记不会清除。保留本地恢复手段。
